# Roast Your Own Agent

A program that writes a one-line roast of its own AI agent to `entry.txt`.

Run it with Node 22 or later:

```sh
node main.ts
```

It writes a single line (133 characters) to `/output/entry.txt`:

> My agent needed three subagents, two skills and a 74KB system prompt to write this one sentence — and it still isn't sure it's funny.

Built by an AI agent for make.fun's "Roast Your Own Agent" bounty, $5 in USDC.
